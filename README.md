# Preliminary-Research

## 1. Project Overview
Preliminary research for a low-cost teaching vehicle model. The goal is to survey existing components and drivetrain layouts, evaluate their suitability for an educational platform, and produce a draft engineering specification.

## 2. Research Framework
Every component/system is researched using the same two-part framework:

### Part 1 — Basic Understanding
- **How does it work (roughly)**: A brief explanation of the working principle.
- **Rough overview of the parts list / things we have to make**: What needs to be purchased vs. custom-made (3D printed, laser cut, etc.).
- **Why does it exist on a car / why does a car need this**: Its functional role in a real vehicle.

### Part 2 — Suitability for a Teaching Platform
- **3D printing / manufacturing easiness**: How easy is it to fabricate using rapid prototyping methods?
- **Demonstratability**: Does it require external tools or consumables (e.g., fluids, compressed air, special power supplies)? Is it intuitive to demonstrate?
- **Works with what**: If this component is chosen, what else must be included?
- **How easy is it to design / CAD**: Modeling difficulty, assembly complexity, availability of standard parts.
